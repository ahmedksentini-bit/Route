Route — aide rapide

  1. Fond : importer un DXF (ou un DWG si l'URL du convertisseur est renseignée). Choisir les calques et les règles d'extraction, puis Construire le TIN.
  2. Axe : activer « ＋ Sommets » et cliquer sur le plan ; saisir R (et A) sur les sommets intermédiaires. Les points KA/KE/T1/T2 et les contrôles ARP s'affichent.
  3. Rasante : sur le profil en long, « Auto » ou « ＋ Sommets » ; saisir Rv pour les raccordements paraboliques.
  4. Profil type : chaussée, accotements, talus, fossé → profils en travers, surfaces et cubatures.
  5. Exporter : DXF (plan, PL, PT), LandXML (Covadis, Civil 3D), CSV.

Molette = zoom, glisser = déplacer, glisser un sommet = le déplacer. Le projet s'enregistre en JSON (et se mémorise dans le navigateur).
